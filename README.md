# Republic Clothing

A responsive storefront for Republic Clothing featuring the product photos in `Republic Clothing/`. Product orders open WhatsApp with the selected item and listed price; customers can ask about sizes and availability directly.

## Run locally

Open `index.html` in a browser, or serve this repository with any static web server.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and select the `main` branch and `/ (root)` as the publishing source. The storefront will then be available at the Pages URL GitHub provides.
